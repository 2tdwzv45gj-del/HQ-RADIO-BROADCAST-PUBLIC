# HQ RADIO BROADCAST

**The World, in High Quality**

HQ RADIO BROADCAST is a web app for discovering and listening to radio stations from around the world.

## Features

- Browse a curated radio catalog.
- Search and filter stations.
- Listen to radio streams directly in the app.
- Manage favorites and personal stations.
- View station logos, with visual fallbacks when a logo is unavailable.
- Explore station information such as country, genres, codec and declared bitrate.

## Requirements

- Node.js compatible with the project.
- npm.

## Run locally

Install dependencies:

    npm install

Start the development server:

    npm run dev

Open http://localhost:3000 in your browser.

## Production build

    npm run build
    npm run start

## Catalog data

The public catalog uses the curated station data in `data/curated_stations.json`, with supporting data for station metadata and logos.

## Project status

The app is under active development. Features and deployment settings may evolve as testing continues.
